Getting started

Install, set up, play.

Fluxlator runs Windows software through Wine and related compatibility components. Results depend on your hardware and the title.

Download the APK

Open the release below on your ARM64 Android device and download the 0.1.3 APK.

Install on Android

Open the downloaded file. Android may ask you to allow installs from the app opening the APK.

Create a container

Choose a profile in the container settings, then add your own legally obtained Windows software.

i

Community preview. Fluxlator is derived from Winlator and is not an official Winlator release. It currently launches user-created Windows shortcuts and does not connect Steam, Epic, GOG, or Amazon libraries. This build is debug-signed and may not run every game. Roblox compatibility is not guaranteed; Fluxlator does not hide from or bypass anti-cheat systems. Windows and game licenses are not included.
